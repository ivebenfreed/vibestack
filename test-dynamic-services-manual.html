📋 Manual Test Script

Copy and paste these commands into the browser console on the LiveStore debug page:

1. Check Dynamic Services Available:

console.log('🔍 Checking dynamic services...', {
  available: !!window.liveStoreDomain,
  services: !!window.liveStoreDomain?.services,
  orgId: localStorage.getItem('vibestack-last-organization-id')
});

2. Test Dynamic Project Creation:

window.liveStoreDomain.services.project.create({
  name: 'Manual Test Project',
  description: 'Testing dynamic schema adaptation',
  status: 'active',
  priority: 'high',
  budget: 85000
}).then(result => {
  console.log('📦 Project creation result:', result);
  if (result.success) {
    console.log('✅ Dynamic project created successfully!');
  } else {
    console.log('❌ Project creation failed:', result.error);
    console.log('🔍 Validation errors:', result.validationErrors);
  }
});

3. Test Dynamic Skill Creation:

window.liveStoreDomain.services.skill.create({
  name: 'Manual Testing',
  category: 'technical',
  level: 'expert',
  description: 'Manual testing of dynamic LiveStore services'
}).then(result => {
  console.log('🎯 Skill creation result:', result);
  if (result.success) {
    console.log('✅ Dynamic skill created successfully!');
  } else {
    console.log('❌ Skill creation failed:', result.error);
  }
});

4. Test Schema Validation:

window.liveStoreDomain.services.project.create({
  // Missing required 'name' field to test validation
  description: 'This should fail validation',
  invalidField: 'This should be filtered out'
}).then(result => {
  console.log('🔍 Validation test result:', result);
  if (!result.success && result.validationErrors) {
    console.log('✅ Schema validation working correctly!');
  } else {
    console.log('⚠️ Validation may not be working as expected');
  }
});

5. Test Custom Entity Service:

try {
  const customService = window.liveStoreDomain.services.forCurrentOrg('CustomEntity');
  console.log('🔧 Custom entity service created:', !!customService);
  console.log('🔧 Available methods:', Object.keys(customService));
} catch (error) {
  console.log('⚠️ Custom entity service error:', error.message);
}

6. Run Full Integration Test:

window.liveStoreDomain.test().then(result => {
  console.log('🚀 Full integration test result:', result);
  if (!result.error) {
    console.log('✅ All dynamic services working!');
  } else {
    console.log('❌ Integration test failed:', result.error);
  }
});

7. Check Sync Status:

const syncStatus = window.liveStoreDomain.syncStatus();
console.log('🔄 Sync status:', syncStatus);

✅ Expected Results

  • Dynamic Services Available: Should show services object and current org ID
  • Project Creation: Should create with Wide Corp's project schema fields
  • Skill Creation: Should create with Wide Corp's skill schema fields
  • Validation: Should fail when required fields are missing
  • Custom Entities: Should create services for any org-defined entity
  • Integration Test: Should complete without errors
  • Sync Status: Should show connected status

🎯 Key Features Being Tested

  • Schema Adaptation: Services adapt to Wide Corp's custom entity schemas
  • Field Validation: Data validated against organization-specific field definitions
  • Type Conversion: Automatic conversion of field types (string→number, JSON→object)
  • Dynamic Entity Creation: Support for any entity type defined in org schema
  • Error Handling: Proper error messages and validation feedback
  • Organization Isolation: Operations scoped to current organization
