Manual Test: Dependency Selection and Deletion

Prerequisites:

  • Make sure dev servers are running on port 5703
  • Make sure you're logged in

Test Steps:

  1. Open: http://localhost:5703/debug/vibegantt
  2. Wait for the Gantt chart to load with tasks and dependencies
  3. Test 1: Single Selection
    • Click on any dependency line (should turn blue/selected)
    • Press Delete key
    • Dependency should disappear
  4. Test 2: Multi Selection
    • Click on a dependency line
    • Ctrl+Click (or Cmd+Click on Mac) on another dependency
    • Both should be selected
    • Press Delete key
    • Both dependencies should disappear
  5. Test 3: Clear Selection
    • Click on a dependency to select it
    • Click on empty space in the chart
    • Selection should be cleared
  6. Test 4: Delete Button
    • Click on a dependency to select it
    • A delete button should appear on the selected dependency
    • Click the delete button
    • Dependency should disappear

Expected Console Logs:

  • When clicking dependency: "GanttEventDelegationManager: Dependency clicked"
  • When pressing Delete: "GanttMachine: Delete key pressed"
  • When deleting: "EntityDependencyService: Deleted entity dependency"

Troubleshooting:

  • If Delete key doesn't work, click on the Gantt chart first to focus it
  • Open browser console (F12) to see debug logs
  • Make sure you see dependencies rendered as arrow lines between tasks
