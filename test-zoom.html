Testing Ctrl+Scroll zoom on VibeGantt

  • Open http://localhost:5593/debug/vibegantt
  • Hold Ctrl (or Cmd on Mac) and scroll with mouse wheel
  • Check browser console for "Zoom requested:" messages
  • Check for "Zoom: day -> week" type messages

Expected Behavior:

  • Ctrl+Scroll UP should zoom IN (more detail, hour -> day -> week)
  • Ctrl+Scroll DOWN should zoom OUT (less detail, day -> week -> month)
  • The timeline should update to show different time scales
