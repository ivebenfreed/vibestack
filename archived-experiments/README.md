# Archived Experiments

This directory contains experimental apps and prototypes that were moved out of the main `apps/` directory to prevent conflicts with the Turborepo monorepo setup.

## Contents:

- **solid-app-experiment/**: SolidJS prototype that was causing Turborepo binary conflicts
  - Originally attempted as `solicit-js` app
  - Complete UI implementation with SolidStart
  - Moved here to preserve work while fixing monorepo issues

## Usage:

These experiments can be developed independently outside the main monorepo structure. If needed, they can be moved back or properly integrated with updated tooling.
