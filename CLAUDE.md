## Session Tracking Rules

When working in this project, Claude should:

1. **On First Request**: Update `.claude/sessions/[current]/plan.md` with:
   - User's goals
   - Planned approach
   - Expected deliverables

2. **During Work**: Maintain `.claude/sessions/[current]/work-log.md` with:
   - Time-stamped progress updates
   - Files modified
   - Decisions made

3. **Use Git**: 
   - Commit after each logical chunk of work
   - Use descriptive commit messages
   - Format: `[Feature] Brief description`
