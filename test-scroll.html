VibeGridX Scroll Event Test

Open the browser console and navigate to a page with VibeGridX. Then try scrolling the grid.

You should see:

  • "🎯 EventDelegationManager: Attaching scroll listener to viewport" when the grid loads
  • "🎯 EventDelegationManager: Scroll event" messages when you scroll

Expected Console Output:

🎯 EventDelegationManager: Viewport not found, retrying in 100ms
🎯 EventDelegationManager: Attaching scroll listener to viewport
🎯 EventDelegationManager: Scroll event {scrollTop: 0, scrollLeft: 0, timestamp: 12345.67}
🎯 EventDelegationManager: Scroll event {scrollTop: 120, scrollLeft: 0, timestamp: 12456.78}
...

Steps to Test:

  1. Open the browser developer console (F12)
  2. Navigate to http://localhost:5175/tasks or another page with VibeGridX
  3. Look for the "Attaching scroll listener" message in the console
  4. Scroll the data grid vertically
  5. Verify that "Scroll event" messages appear in the console
